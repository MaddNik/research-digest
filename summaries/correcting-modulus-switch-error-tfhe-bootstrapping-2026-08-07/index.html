Correcting the modulus switch error in TFHE bootstrapping for real-valued computation

IACR ePrint 2026/1533 · full view ↗

Overview and contribution

Thomas Crasson (AMIAD, Pôle Recherche, Palaiseau) and Florian Méhats (Sopra Steria Defense & Security, CS Research Lab) attack the precision ceiling of TFHE Programmable Bootstrapping (PBS) on real-valued inputs. The paper is dated 2026-07-27 and posted to the IACR Cryptology ePrint Archive as report 2026/1533 (CC BY 4.0).

The bottleneck they target is the modulus switch that both the GINX and the AP bootstrapping algorithms perform, moving an LWE ciphertext from modulus $q$ down to $2N$, where $N$ is the look-up-table (test polynomial) degree. That step rounds, and the rounding injects an error $e_{MS}$ directly onto the plaintext. Because $e_{MS}$ is an error on the input of the evaluated function, no amount of downstream cleanup removes it, and it is what forces the plaintext space to be quantized. Under the paper's parameters, $e_{MS}$ has standard deviation about $1.9 \times 10^{-3}$, while the blind-rotate noise $e_{BS}$ sits at about $2.7 \times 10^{-5}$: the modulus switch dominates by roughly two orders of magnitude.

The contribution is a correction algorithm applied after bootstrapping rather than a way of avoiding the modulus switch. It performs a first-order Taylor expansion in the encrypted domain:

$$f(x) = f(x_0) - e_{MS} f'(x_0) + O(e_{MS}^2),$$

where $x_0$ is the post-modulus-switch value actually seen by the blind rotate. To get $f(x_0)$ and $f'(x_0)$ without paying for a second bootstrap, the authors use the many-LUT technique of Chillotti, Ligier, Orfila and Tap with $u = 1$, packing $f$ and $f'$ into a single test polynomial and extracting both from one blind rotate. The correction term is then assembled homomorphically from a new evaluation key (the "recovery key"), at a cost of two external products plus $n$ plaintext/ciphertext multiplications, negligible against the $n$ sequential external products of the bootstrap itself.

Headline results: a tenfold reduction in output noise standard deviation on sigmoid, tanh and ciphertext/ciphertext real multiplication, matching a heuristic average-case noise model to three significant figures; and a proof-of-concept application, numerical integration of ordinary differential equations over encrypted initial conditions, which the authors state has not been investigated before.

Scope: this is not classical small-integer TFHE

The paper is explicit that it does not target the standard TFHE regime for small integers. There, the test polynomial carries redundancy, repeating each LUT value over a window of coefficients, so the modulus switch error is absorbed as long as it does not push the rotation out of its window. The correction proposed here would be pointless in that setting.

Instead the authors work in a regime closer in spirit to CKKS: the plaintext $x$ is not quantized before encryption, the noise $e$ induces an irrecoverable approximation error on $x$ exactly as in an approximate scheme, and bootstrapping is used to evaluate nonlinear functions on genuinely real-valued ciphertexts. The test polynomial carries no redundancy, so the input interval $[-\tfrac{1}{4}, \tfrac{1}{4}]$ is quantized onto the full $N$ available values. It is the resulting unavoidable approximation cost of the modulus switch that the Taylor correction mitigates.

Prior work is grouped into three lines, all of which the paper contrasts against. First, making bootstrapping tractable for large LUTs to increase the number of representable values. Second, splitting large-bit messages into sub-messages and building arithmetic (sometimes floating-point) on top of the decomposition. Both of these need several bootstraps per function evaluation. Third, reducing modulus switch noise by merging several CMUX steps inside GINX bootstrapping, which inflates key size and complexity, exponentially in the number of merged steps for one of the cited approaches. Recent CKKS-side functional bootstrapping work is noted as operating on bits or small integers, not continuous real inputs.

Security caveat. Because decryption is approximate, the scheme lives in the IND-CPAD model rather than plain IND-CPA, exposing it in principle to the Li-Micciancio attack via a decryption oracle. The authors note that standard noise flooding before decryption restores IND-CPAD security, and that their target applications are compute-only server-side settings where the server never decrypts.

Background: ciphertexts and noise model

Polynomials are written with capitals, torus elements with lowercase. Let $(q, n, N) \in \mathbb{N}^3$, $\mathbb{T}_N = \mathbb{T}[X]/(X^N + 1)$ with $\mathbb{T}$ the real torus, and $\mathcal{R}_N = \mathbb{Z}[X]/(X^N + 1)$. The secret key is $S = (S_i)_{i \in \{0,\dots,n-1\}} \in \mathcal{R}_N^n$, whose coefficients may be binary or ternary; this paper considers only binary keys.

Definition 1 (GLWE). The GLWE encryption of a plaintext $x \in \mathbb{T}_N$ is

$$\mathrm{GLWE}^{n,N}_S(x) = \left( A_0, \dots, A_{n-1},\; B = \sum_{i=0}^{n-1} A_i \cdot S_i + x + e \bmod 1 \right),$$

with $(A_i)$ sampled from $\mathbb{T}_N^n$ and $e \in \mathbb{T}_N$ Gaussian noise. An $\mathrm{LWE}^n_s$ ciphertext is the case $N = 1$ (vector key, written lowercase); an $\mathrm{RLWE}^N_S$ ciphertext is the case $n = 1$. In practice one works in the discrete torus $\tfrac{1}{q}\mathbb{Z}_q$.

Definition 2 (RLev). With $n = 1$, level $\ell$ and base $\beta$:

$$\mathrm{RLev}^{\beta,\ell}_S(x) = \left( \mathrm{RLWE}^N_S(x/\beta), \dots, \mathrm{RLWE}^N_S(x/\beta^\ell) \right).$$

Definition 3 (RGSW).

$$\mathrm{RGSW}^{\beta,\ell}_S(x) = \left( \mathrm{RLev}^{\beta,\ell}_S(-S \cdot x),\; \mathrm{RLev}^{\beta,\ell}_S(x) \right).$$

Noise model. Noise growth is tracked with a standard average-case Central Limit Theorem approach, following Costache et al. and Murphy and Player: each noise polynomial coefficient is modelled as an i.i.d. normal random variable, so variances add and a single scalar suffices per step. The authors cite evidence that this gives tighter and more representative estimates than worst-case subgaussian bounds, and they validate it empirically over 10000 trials in the experiments.

Background: fundamental homomorphic operations

Ciphertext addition. Componentwise modulo 1; output noise variance is the sum of the input variances.

Plaintext/ciphertext multiplication. For $P \in \mathcal{R}_N$, every component is scaled:

$$P \cdot \mathrm{GLWE}^{n,N}_S(x) = \left( P \cdot A_0, \dots, P \cdot A_{n-1}, P \cdot B \right) = \mathrm{GLWE}^{n,N}_S(P \cdot x).$$

Output noise variance is the input variance scaled by $\lVert P \rVert_2^2$.

Gadget decomposition. $\mathrm{Dec}^{\beta,\ell}(a) = (a^{(1)}, \dots, a^{(\ell)})$ is the signed base-$\beta$ decomposition of $a \in \mathbb{T}_N$:

$$a \approx \sum_{j=1}^{\ell} a^{(j)} \beta^{-j}, \qquad a^{(j)} \in \left[ -\tfrac{\beta}{2}, \tfrac{\beta}{2} \right],$$

with approximation error uniform on $\mathcal{U}(-\beta^{-\ell}/2, \beta^{-\ell}/2)$.

External product. Taking $\mathrm{RLWE}^N_S(P_1) = (A,B)$ and $\mathrm{RGSW}^{\beta,\ell}_S(P_2)$, it outputs $\mathrm{RLWE}^N_S(P_1 \cdot P_2)$:

$$\mathrm{RLWE}^N_S(P_1) \boxdot \mathrm{RGSW}^{\beta,\ell}_S(P_2) = \sum_{j=1}^{\ell} A^{(j)} \cdot \mathrm{RLWE}^N_S(-P_2 \cdot S/\beta^j) + \sum_{j=1}^{\ell} B^{(j)} \cdot \mathrm{RLWE}^N_S(P_2/\beta^j),$$

with output noise variance

$$\sigma^2_{\mathrm{ext}} = \lVert P_2 \rVert_2^2 \left( \sigma^2_{\mathrm{RLWE}} + \frac{N}{24 \beta^{2\ell}} \right) + \frac{\ell N \beta^2}{6} \sigma^2_{\mathrm{RGSW}}.$$

Modulus switching. Scaling an $\mathrm{LWE}_S$ ciphertext $(a_0,\dots,a_{n-1},b) \in \mathbb{T}^{n+1}$ from modulus 1 to $q'$ (typically $q' = 2N$):

$$\mathrm{ModSwitch}_{q'}(a_0,\dots,a_{n-1},b) = (\lfloor q' a_0 \rceil, \dots, \lfloor q' a_{n-1} \rceil, \lfloor q' b \rceil).$$

The message is preserved under the same key. Rounding injects noise of variance $n/24$ in the integer domain $\mathbb{Z}_{q'}$ for a binary key. Crucially this variance is independent of $q'$, since the rounding errors $\lfloor q' a_i \rceil - q' a_i$ are uniform on $[-\tfrac{1}{2}, \tfrac{1}{2})$ for any $q'$.

SampleExtract. Converts $\mathrm{RLWE}^N_S(P)$ with $P = \sum_{m=0}^{N-1} p_m X^m$ into an LWE ciphertext of a single chosen coefficient $p_\alpha$, for free. With $A = \sum_m A_m X^m$, $B = \sum_m B_m X^m$ and extracted key $\bar{s} = (s_0,\dots,s_{N-1})$, the output is $(\bar{a}_0,\dots,\bar{a}_{N-1},\bar{b})$ with $\bar{b} = B_\alpha$ and

$$\bar{a}_j = \begin{cases} A_{\alpha - j} & \text{if } 0 \le j \le \alpha, \\ -A_{\alpha - j + N} & \text{if } \alpha < j \le N-1. \end{cases}$$

The result carries the same noise as the extracted coefficient and costs nothing.

Classical PBS and where the error comes from

PBS maps $\mathrm{LWE}^n_s(x)$ to $\mathrm{LWE}^N_{\bar{s}}(f(x))$ for arbitrary $f$, in four phases: (1) a key switch that moves the input ciphertext from a key of size $N$, the RLWE polynomial degree, down to a smaller LWE key of dimension $n$; (2) a modulus switch; (3) a blind rotate; (4) a sample extract. The paper drops the initial key switch from the analysis and starts from $\mathrm{LWE}^n_s(x) = (a_0,\dots,a_{n-1},b)$ with initial noise $e_{\mathrm{init}}$. Throughout, $x \in [-\tfrac{1}{4} + \delta, \tfrac{1}{4} - \delta]$ with $\delta > 0$ satisfying $\delta \gg \lVert e_{\mathrm{init}} + e_{MS} \rVert$, so non-periodic functions do not overflow the torus.

Modulus switch. $\tilde{a}_i = \lfloor 2N a_i \rceil$ for $0 \le i \le n-1$, and $\tilde{b} = \lfloor 2N b \rceil$. Define

$$i_0 = \tilde{b} - \sum_i \tilde{a}_i s_i \bmod 2N, \qquad x_0 = \frac{i_0}{2N},$$

with the representative $i_0$ taken in $[-N, N)$. The induced error is

$$e_{MS} = x_0 - x - e_{\mathrm{init}} = \frac{1}{2N} \left( \tilde{b} - 2Nb - \sum_{i=0}^{n-1} (\tilde{a}_i - 2N a_i) s_i \bmod 2N \right).$$

Since $x$ lies in $[-1/4 + \delta, 1/4 - \delta]$ and the errors are small, $x_0 \in (-1/4, 1/4)$ and $i_0 \in (-N/2, N/2)$. For uniformly sampled $a_i$,

$$\mathrm{Var}(e_{MS}) = \frac{n}{96 N^2}.$$

Blind rotate. The test polynomial for $f$ has coefficients $v_i = f\!\left(\tfrac{i}{2N}\right)$ for $-\tfrac{N}{2} \le i \le \tfrac{N}{2} - 1$, with no redundancy. Blind rotate computes an RLWE encryption of $X^{-\tilde{b} + \sum_i \tilde{a}_i s_i} v(X) = X^{-i_0} v(X)$ using $n$ sequential external products against the bootstrapping key $(\mathrm{RGSW}^{\ell_{BS}, \beta_{BS}}_S(s_i))_i$. The output noise variance is

$$\sigma^2_{BS} = nN \left( \frac{\ell_{BS} \beta_{BS}^2 \sigma^2_{BSK}}{6} + \frac{1}{24 \beta_{BS}^{2\ell}} \right),$$

with $\sigma_{BSK}$ the bootstrapping key standard deviation. A SampleExtract of coefficient 0 then yields $\mathrm{LWE}^N_{\bar{s}}(v_{i_0}) = \mathrm{LWE}^N_{\bar{s}}(f(x_0))$.

The resulting PBS error. Decryption returns $f(x_0) + e_{BS}$ rather than $f(x)$, so

$$f(x_0) + e_{BS} - f(x) = f(x + e_{MS} + e_{\mathrm{init}}) - f(x) + e_{BS}.$$

This equation is the starting point of the whole paper. For the parameters of the experiments, $\sigma(e_{MS}) \approx 1.9 \times 10^{-3}$ against $\sigma(e_{BS}) \approx 2.7 \times 10^{-5}$. Reducing $e_{MS}$ conventionally means increasing $N$, which costs a proportional increase in bootstrapping complexity. Because $e_{MS}$ acts as irrecoverable noise on the input $x$, it caps the precision of any function evaluation.

Many-LUT PBS

The many-LUT refinement evaluates $2^u$ functions $f_0, \dots, f_{2^u - 1}$ in one bootstrap by coarsening the modulus switch to a multiple of $2^u$:

$$\tilde{a}_i = 2^u \left\lfloor \frac{2N a_i}{2^u} \right\rceil, \qquad \tilde{b} = 2^u \left\lfloor \frac{2N b}{2^u} \right\rceil,$$

which inflates the modulus switch variance to

$$\mathrm{Var}(e_{MS}) = \frac{n \, 2^{2u}}{96 N^2}.$$

The test polynomial interleaves the LUTs:

$$v_i = f_j\!\left( \frac{2^u k}{2N} \right) \quad \text{for } 0 \le i \le N-1, \quad k = \left\lfloor \frac{i}{2^u} \right\rfloor, \quad j = i - 2^u k.$$

After the blind rotate, extracting the first $2^u$ coefficients yields $\mathrm{LWE}^N_{\bar{s}}(f_j(x_0))$ for each $j$. There is a direct trade-off between the number $2^u$ of evaluated functions and the added modulus switch noise. The paper uses $u = 1$ throughout, recovering encryptions of $f$ and $f'$ from a single bootstrap and paying a factor $2^{2u} = 4$ in $\mathrm{Var}(e_{MS})$, that is $\mathrm{Var}(e_{MS}) = n/(24N^2)$.

The encrypted Taylor correction

Assuming $e_{\mathrm{init}} \ll e_{MS}$ and dropping $e_{\mathrm{init}}$, the method computes an encryption of $e_{MS} f'(x_0)$ and subtracts it from the PBS output $\mathrm{LWE}^N_{\bar{s}}(f(x_0))$.

Two obstacles. First, the terms defining $e_{MS}$ are real-valued fractional numbers in $[-1,1]$, but homomorphic multiplication needs integer operands, so $e_{MS}$ cannot be multiplied into $\mathrm{LWE}^N_{\bar{s}}(f'(x_0))$ directly. Second, the terms $(2\lfloor N a_i \rceil - 2N a_i)s_i$ cannot be computed in the clear because $s_i$ is secret. The authors note that prior work (de Ruijter, Verbauwhede and D'Anvers) replaces each $s_i$ by its expectation $\mathbb{E}(s_i)$ and injects the correction during the modulus switch, before the blind rotate, which halves $\mathrm{Var}(e_{MS})$ for binary keys.

Two solutions. A scaling factor $\rho$ turns the real quantities into integers: one computes $\lfloor \rho(2\lfloor N b \rceil - 2Nb) \rceil$ and $\lfloor \rho(2\lfloor N a_i \rceil - 2N a_i) \rceil$, extracting $\log_2(\rho)$ bits of information, and encodes the derivative in the LUT as $f'/(2N\rho)$ so the scaling cancels. For the secret key, a fresh evaluation key, the recovery key $(\mathrm{RGSW}^{\beta_{RK}, \ell_{RK}}_S(s_i))_{i \in \{0,\dots,n-1\}}$, lets the sum be formed homomorphically:

$$\sum_{i=0}^{n-1} \left\lfloor \rho (2\lfloor N a_i \rceil - 2N a_i) \right\rceil \, \mathrm{RGSW}^{\beta_{RK}, \ell_{RK}}_S(s_i).$$

Splitting the error. The modulus switch error is decomposed into a rounding part and a many-LUT part, $e_{MS} = \tfrac{1}{2N}(e_R + e_{ML})$, with

$$e_R = \lfloor 2Nb \rceil - 2Nb - \sum_{i=0}^{n-1} (\lfloor 2N a_i \rceil - 2N a_i) s_i,$$$$e_{ML} = 2\lfloor Nb \rceil - \lfloor 2Nb \rceil - \sum_{i=0}^{n-1} (2\lfloor N a_i \rceil - \lfloor 2N a_i \rceil) s_i.$$

Writing $\hat{b}_R = \lfloor 2Nb \rceil - 2Nb$, $\hat{a}_{R,i} = \lfloor 2N a_i \rceil - 2N a_i$, $\hat{b}_{ML} = 2\lfloor Nb \rceil - \lfloor 2Nb \rceil$ and $\hat{a}_{ML,i} = 2\lfloor N a_i \rceil - \lfloor 2N a_i \rceil$, the key observation is that $e_{ML}$ is already a sum of integers and needs no scaling, while $e_R$ is real-valued and does. Only the latter gets the $\rho$ treatment:

$$e_{\rho R} = \lfloor \rho \hat{b}_R \rceil - \sum_{i=0}^{n-1} \lfloor \rho \hat{a}_{R,i} \rceil s_i.$$

The test polynomial. Even coefficients carry $f/2$, odd coefficients carry $f'/(2N\rho)$:

$$v(X) = \sum_{i=-N/4}^{N/4 - 1} \frac{1}{2} f\!\left( \frac{i}{N} \right) X^{2i} + \frac{1}{2N\rho} f'\!\left( \frac{i}{N} \right) X^{2i+1},$$

where negative powers are read modulo $X^N + 1$, that is $X^{-k} \equiv -X^{N-k}$ in $\mathcal{R}_N$.

How the two correction terms are formed. The term $\tfrac{f'(x_0)}{2N} e_R$ is approximated by $\tfrac{f'(x_0)}{2N\rho} e_{\rho R}$, read off coefficient 1 of the rotated polynomial after an external product with the RGSW-encoded $e_{\rho R}$. The term $\tfrac{f'(x_0)}{2N} e_{ML}$ is approximated by the forward difference

$$\frac{f(x_0 + \tfrac{1}{N}) - f(x_0)}{2} \, e_{ML},$$

which is exactly the difference of coefficients 2 and 0 of the rotated test polynomial, obtained from a second external product.

Cost. The overhead is the $n$-iteration loop building the two RGSW accumulators plus two external products. Since the bootstrap itself is $n$ sequential external products, the overhead is negligible against bootstrapping latency. The authors note the algorithm could be combined with the "collapse" technique of Chartier, Koskas, Lemou and Mehats and of Zhou et al. to push precision further.

Noise analysis

Proposition 1 (heuristic). For a smooth $f: \mathbb{T} \to \mathbb{T}$, recovery key noise variance $\sigma^2_{RK}$, input key size $n$, LUT degree $N$ and scaling factor $\rho$, the output of the correction algorithm carries two noises.

(i) A centred FHE noise $e_{\mathrm{fhe}}$ of variance

$$\sigma^2_{\mathrm{fhe}} = 4\sigma^2_{BS} + \frac{n}{2}\left( \frac{\rho^2}{12} + 1 \right)\left( \sigma^2_{BS} + \frac{N}{24 \beta_{RK}^{2\ell_{RK}}} + \frac{\ell_{RK} N \beta_{RK}^2 \sigma^2_{RK}}{3} \right) + \frac{n}{24}\left( \frac{f'(x)}{2N\rho} \right)^2.$$

The factor 4 on $\sigma^2_{BS}$ comes from the factor 2 applied when extracting $f(x_0)$ (the LUT stores $f/2$).

(ii) A Taylor truncation error $e_{\mathrm{trunc}} = \tfrac{1}{2} f''(x) e_{MS}^2$, purely numerical, with mean

$$\mu_{\mathrm{trunc}} = \frac{n f''(x)}{48 N^2}.$$

The $\rho$ trade-off. Equation (19) exposes it plainly: larger $\rho$ shrinks the last term (the bits of $\hat{b}_R$, $\hat{a}_{R,i}$ discarded by rounding) but inflates the middle term through $\rho^2/12$ (more RGSW noise carried by larger integer weights). Minimizing gives the optimum.

Corollary 1.

$$\rho_{\mathrm{opt}} = \sqrt{\frac{|f'(x)|}{2N}} \left( \sigma^2_{BS} + \frac{N}{24 \beta_{RK}^{2\ell_{RK}}} + \frac{N \ell_{RK} \beta_{RK}^2 \sigma^2_{RK}}{3} \right)^{-1/4},$$

at which

$$\sigma^2_{\mathrm{fhe}} = 4\sigma^2_{BS} + \frac{n}{2}\left( \sigma^2_{BS} + \frac{N}{24 \beta_{RK}^{2\ell_{RK}}} + \frac{\ell_{RK} N \beta_{RK}^2 \sigma^2_{RK}}{3} \right) + \frac{n|f'(x)|}{24N} \left( \sigma^2_{BS} + \frac{N}{24 \beta_{RK}^{2\ell_{RK}}} + \frac{N \ell_{RK} \beta_{RK}^2 \sigma^2_{RK}}{3} \right)^{1/2}.$$

Remark on $f'(x)$. The last term depends on $f'$ evaluated at the unknown plaintext $x$. Since $f$ is fixed and known in advance, one can substitute $\lVert f' \rVert_\infty$ for a conservative worst-case bound suitable for parameter selection, or a representative value such as $f'(0)$ or $\mathbb{E}[f'(x)]$ when $f'$ varies little over the domain.

Proof sketch (Appendix). The variance splits as $\sigma^2_{\mathrm{fhe}} = 4\sigma^2_{BS} + \sigma^2_{\mathrm{correction}}$ and $\sigma^2_{\mathrm{correction}} = \sigma^2_{\mathrm{product}} + \sigma^2_{\mathrm{approx}}$. Applying the external product formula to $v_{\mathrm{out}}(X) = v(X) X^{-\tilde{b} + \sum_i \tilde{a}_i s_i}$, with a factor 2 on the $e_{ML}$ terms because line 12 subtracts two independent SampleExtracts:

$$\sigma^2_{\mathrm{product}} = \left( \mathbb{E}(\lVert e_{\rho R} \rVert_2^2) + 2\,\mathbb{E}(\lVert e_{ML} \rVert_2^2) \right)\left( \sigma^2_{BS} + \frac{N}{24\beta_{RK}^{2\ell_{RK}}} \right) + \frac{\ell_{RK} N \beta_{RK}^2}{6}\left( \sigma^2_{\mathrm{RGSW}(e_{\rho R})} + 2 \sigma^2_{\mathrm{RGSW}(e_{ML})} \right).$$

The $\hat{a}_{R,i}$ are uniform on $[-1/2, 1/2]$ and the $\hat{a}_{ML,i}$ take values in $\{-1, 0, 1\}$ with probabilities $\{1/4, 1/2, 1/4\}$. With a uniform binary key this gives

$$\sigma^2_{\mathrm{RGSW}(e_{\rho R})} = \frac{n\rho^2}{12}\sigma^2_{RK}, \qquad \sigma^2_{\mathrm{RGSW}(e_{ML})} = \frac{n}{2}\sigma^2_{RK},$$$$\mathbb{E}(\lVert e_{\rho R} \rVert_2^2) = \frac{n\rho^2}{24}, \qquad \mathbb{E}(\lVert e_{ML} \rVert_2^2) = \frac{n}{4},$$

hence

$$\sigma^2_{\mathrm{product}} = \frac{n}{2}\left( \frac{\rho^2}{12} + 1 \right)\left( \sigma^2_{BS} + \frac{N}{24\beta_{RK}^{2\ell_{RK}}} + \frac{\ell_{RK} N \beta_{RK}^2 \sigma^2_{RK}}{3} \right).$$

The rounding-of-$\rho$ term is

$$e_{\mathrm{approx}} = \frac{f'(x_0)}{2N\rho}\left( \rho \hat{b}_R - \lfloor \rho \hat{b}_R \rceil - \sum_{i=0}^{n-1} (\rho \hat{a}_{R,i} - \lfloor \rho \hat{a}_{R,i} \rceil) s_i \right),$$

and since $\rho \hat{a}_{R,i} - \lfloor \rho \hat{a}_{R,i} \rceil$ is uniform on $[-1/2, 1/2]$ with a binary key,

$$\sigma^2_{\mathrm{approx}} = \left( \frac{f'(x)}{2N\rho} \right)^2 \frac{n}{24}.$$

Here $f'(x_0)$ is identified with $f'(x)$ since $x_0 = x + e_{\mathrm{init}} + e_{MS}$ gives $f'(x_0) = f'(x) + O(e_{MS})$, beyond the order of approximation considered. For the truncation term, $e_{MS}$ is centred normal with $\mathrm{Var}(e_{MS}) = n/(24N^2)$ (many-LUT with $u=1$), so $\mathbb{E}(e_{\mathrm{trunc}}) = \tfrac{f''(x)}{2} \cdot \tfrac{n}{24N^2} = \tfrac{n f''(x)}{48 N^2}$.

Experiments: numerical integration of ODEs under encryption

As a proof of concept the authors integrate a toy one-dimensional ODE with encrypted initial coordinates, a use case they state has not been investigated previously. The motivating scenario is an industrial setup where one party holds the initial conditions and another holds the numerical formula. Numerical integration demands high precision, which is exactly what the correction supplies.

The ODE is

$$y'(t) = \cos(t) - y(t)^3,$$

integrated by two schemes, both of the form $y_{n+1} = g_n(y_n)$ where $g_n$ is re-encoded into a fresh LUT at each step, with $f(y,t) = \cos(t) - y^3$:

$$g_n(y) = y + h f(y, t_n) \quad \text{(forward Euler)},$$$$g_n(y) = y + h f\!\left( y + \frac{h}{2} f(y, t_n),\; t_n + \frac{h}{2} \right) \quad \text{(RK2)}.$$

A notable consequence: one PBS per time step for either scheme. All scheme-specific complexity is absorbed into the LUT, so forward Euler and RK2 have identical FHE computation time.

Setup. Initial value $x_0 = 0.1$, 300 distinct ciphertexts of $x_0$, time step $h = 0.025$, $t \in [0, T]$ with $T = 20$. Cryptographic parameters as in Table 1 except $\ell_{BS} = 4$ and $\beta_{BS} = 2^8$. The optimal $\rho$ is 7 for both schemes. The ground truth is an RK45 solution.

Results. Figures 1a and 1b plot the mean absolute error against the RK45 reference: green for plaintext integration, orange for classical PBS, blue for the corrected PBS. For forward Euler, the homomorphic noise is negligible against the scheme's own discretization error, so all three curves are indistinguishable. For RK2, the numerical integration error drops below the homomorphic noise floor required for LWE security, and the correction's advantage becomes visible, the blue corrected curve sitting below the orange classical one across the whole horizon.

The authors are candid that the improvement here is smaller than the tenfold gain of Tables 2 and 3, and give the reason: noise accumulates over $O(1/h)$ bootstrapping steps, each evaluating a function whose output variation is of order $h$, so the per-step signal-to-noise ratio is reduced by a factor $h$ relative to a single function evaluation.

Conclusion and future work

A first-order Taylor correction applied after bootstrapping mitigates the modulus switch error and enables homomorphic computation over real numbers within TFHE, achieving a tenfold reduction in bootstrapping noise standard deviation at negligible computational overhead. Theory and experiment agree on sigmoid, tanh and LWE/LWE multiplication, validating the average-case noise model. Homomorphic numerical integration of ODEs is demonstrated as a new application.

Two directions are proposed for future work. First, extending the correction to a second-order Taylor expansion, at the cost of additional parameters, which could further reduce the truncation error for highly irregular functions. Second, combining the real-number encoding with multivariate function evaluation, opening the way to more complex numerical workflows in the encrypted domain.

Practical takeaways. The method costs one extra evaluation key (the recovery key, $\beta_{RK} = 2^8$, $\ell_{RK} = 8$), halves the usable LUT resolution because the many-LUT $u = 1$ interleaving spends odd coefficients on $f'$, and requires $f'$ to be known analytically at LUT construction time. In exchange it buys roughly 3.3 bits of precision that would otherwise cost an 8- to 16-fold increase in $N$.

Algorithms

The paper contains one formal algorithm. It is reproduced in full below, followed by the standard sub-procedures it invokes, which the body of the paper defines but does not spell out as numbered listings.

Algorithm 1: Taylor expansion correction. In the listing, E_R and E_ML start life as integer scalars and are progressively promoted into $\mathrm{RGSW}^{\beta_{RK},\ell_{RK}}_S$ ciphertexts through the loop, where each plaintext/RGSW operation is understood as a scalar multiple of $\mathrm{RGSW}^{\beta_{RK},\ell_{RK}}_S(1)$.

Algorithm 1: Taylor expansion correction

Input:  Input ciphertext LWE^n_s(x) = (a, b)
Input:  Many-LUT test polynomial v(X) as defined in Eq. (18):
            v(X) = sum_{i=-N/4}^{N/4-1} [ (1/2) f(i/N) X^{2i}
                                        + (1/(2 N rho)) f'(i/N) X^{2i+1} ]
Input:  Recovery key ( RGSW^{beta_RK, l_RK}_S (s_i) )_{i in 0..n-1}
Output: Output ciphertext LWE^N_sbar( f(x) )

 1  (atilde, btilde) = ModulusSwitch(a, b)          # many-LUT variant, u = 1
 2  C := RLWE_S( v(X) * X^{-btilde + sum_{i=0}^{n-1} atilde_i s_i} )
         = BlindRotate(atilde, btilde) with test polynomial v(X)
 3  LWE^N_sbar( f(x0) ) = 2 * SampleExtract(C, 0)
 4  E_R  = round( rho * bhat_R )                    # bhat_R  = round(2Nb) - 2Nb
 5  E_ML = bhat_ML                                  # bhat_ML = 2*round(Nb) - round(2Nb)
 6  for i = 0 to n - 1 do
 7      E_R  -= round( rho * ahat_R,i )  * RGSW^{beta_RK, l_RK}_S (s_i)
 8      E_ML -=        ahat_ML,i         * RGSW^{beta_RK, l_RK}_S (s_i)
 9  C_R  = C (external product) E_R
10  C_ML = C (external product) E_ML
11  LWE^N_sbar( f'(x0) / (2 N rho) * e_rhoR ) = SampleExtract(C_R, 1)
12  LWE^N_sbar( f'(x0) / (2 N)     * e_ML   ) = SampleExtract(C_ML, 2)
                                              - SampleExtract(C_ML, 0)
13  c_out = LWE^N_sbar( f(x0) )
          - LWE^N_sbar( f'(x0) / (2 N rho) * e_rhoR )
          - LWE^N_sbar( f'(x0) / (2 N)     * e_ML   )
14  return c_out

where round(.) is rounding to the nearest integer and, for 0 <= i <= n-1:
    ahat_R,i  = round(2 N a_i) - 2 N a_i           (real, in [-1/2, 1/2])
    ahat_ML,i = 2*round(N a_i) - round(2 N a_i)    (integer, in {-1, 0, 1})

Many-LUT modulus switch (line 1), with $u = 1$.

Input:  LWE^n_s(x) = (a_0, ..., a_{n-1}, b) in T^{n+1}; degree N; u
Output: (atilde, btilde) in Z_{2N}^{n+1}

1  for i = 0 to n - 1 do
2      atilde_i = 2^u * round( 2 N a_i / 2^u )
3  btilde = 2^u * round( 2 N b / 2^u )
4  return (atilde, btilde)

# Induced error variance: Var(e_MS) = n * 2^{2u} / (96 N^2)
# For u = 1 (this paper):  Var(e_MS) = n / (24 N^2)

Blind rotate (line 2). The paper specifies this operation only by its input/output behaviour and its cost, namely $n$ sequential external products between an accumulator RLWE ciphertext and the bootstrapping key. The internal accumulator update rule is not given in the source and is not reproduced here.

Input:  (atilde, btilde) in Z_{2N}^{n+1}
Input:  test polynomial v(X) in T_N
Input:  bootstrapping key ( RGSW^{beta_BS, l_BS}_S (s_i) )_{i in 0..n-1}
Output: RLWE^N_S( v(X) * X^{-i0} ),  i0 = btilde - sum_i atilde_i s_i  mod 2N

1  ACC = RLWE accumulator initialized from v(X) and btilde
2  for i = 0 to n - 1 do
3      ACC = ACC (external product) RGSW^{beta_BS, l_BS}_S (s_i)
           # n sequential external products: the dominant cost of the PBS
4  return ACC

# Output noise variance:
#   sigma^2_BS = n N ( l_BS beta_BS^2 sigma^2_BSK / 6 + 1 / (24 beta_BS^{2 l}) )

SampleExtract (lines 3, 11, 12).

Input:  RLWE^N_S(P) = (A, B),  A = sum_m A_m X^m,  B = sum_m B_m X^m
Input:  target coefficient index alpha in {0, ..., N-1}
Output: LWE^N_sbar( p_alpha ),  sbar = (s_0, ..., s_{N-1}) the coefficients of S

1  bbar = B_alpha
2  for j = 0 to N - 1 do
3      if j <= alpha then  abar_j =  A_{alpha - j}
4      else                abar_j = -A_{alpha - j + N}
5  return (abar_0, ..., abar_{N-1}, bbar)

# No homomorphic cost; noise equals that of the extracted coefficient.

External product (lines 9, 10).

Input:  RLWE^N_S(P1) = (A, B)
Input:  RGSW^{beta,l}_S(P2) = ( RLev^{beta,l}_S(-S*P2), RLev^{beta,l}_S(P2) )
Output: RLWE^N_S(P1 * P2)

1  (A^(1), ..., A^(l)) = Dec^{beta,l}(A)      # signed base-beta decomposition
2  (B^(1), ..., B^(l)) = Dec^{beta,l}(B)
3  return   sum_{j=1..l} A^(j) * RLWE^N_S( -P2 * S / beta^j )
         + sum_{j=1..l} B^(j) * RLWE^N_S(  P2     / beta^j )

# sigma^2_ext = ||P2||_2^2 ( sigma^2_RLWE + N / (24 beta^{2l}) )
#               + (l N beta^2 / 6) sigma^2_RGSW

Encrypted ODE integration (Section 4.3 experiment). One PBS per time step for either scheme; the whole scheme is folded into the LUT.

Input:  LWE encryption of the initial value y_0
Input:  step size h, horizon T, right-hand side f(y, t) = cos(t) - y^3
Input:  scheme in { Euler, RK2 }
Output: LWE encryption of y(T)

1  c = LWE(y_0);  n_steps = T / h
2  for k = 0 to n_steps - 1 do
3      t_k = k * h
4      if scheme == Euler then
5          g(y) = y + h * f(y, t_k)
6      else                                       # RK2
7          g(y) = y + h * f( y + (h/2) * f(y, t_k), t_k + h/2 )
8      build many-LUT test polynomial v_k(X) from g and g'  (Eq. 18)
9      c = Algorithm1( c, v_k, recovery key )     # one PBS per step
10 return c
