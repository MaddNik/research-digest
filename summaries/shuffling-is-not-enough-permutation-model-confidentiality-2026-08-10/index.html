Shuffling is Not Enough: Breaking Permutation-Based Model Confidentiality in Hybrid FHE Inference

IACR ePrint 2026/1527 (ESORICS 2026) · full view ↗

Overview

Hybrid FHE inference splits private inference between two parties: the server homomorphically evaluates each linear layer, the client decrypts the result, applies the nonlinearity in the clear, and re-encrypts for the next round. This avoids the cost of evaluating nonlinearities under FHE, but it hands the client a plaintext view of every intermediate layer output, which would let a curious client read the server's weights directly.

To close that gap, a line of recent systems (Safhire, STIP, Centaur, PermLLM) uses permutation-based model confidentiality: the server permutes the output coordinates of each layer with a secret permutation before returning the ciphertext. Because ReLU commutes with coordinate permutation, the shuffled representation survives across rounds. The security intuition invoked is shuffle-model differential privacy: FHE decryption noise is treated as the local randomizer and the secret output permutation as the shuffler, so privacy should be amplified.

Kim and Lee show this intuition is false in exactly the regime hybrid FHE inference requires. The paper's three contributions:

  • An exact, query-tight recovery theorem. For a $d$-input linear layer on a known quantization lattice of step $\gamma$, correctness forces the additive noise below $\gamma/2$; rounding therefore removes all response-side randomness. With $d+1$ adaptive chosen queries the client recovers a permutation-invariant layer summary exactly, and $d$ queries are necessary.
  • The DP justification is doubly broken. Input DP and model confidentiality quantify different objects (neighboring inputs under a fixed model vs. different models under fixed queries), and the local-DP premise needed for shuffle amplification is unattainable under correctness-bounded noise: it forces $\delta_0 \ge 1$.
  • Concrete impact plus a sharp privacy/utility dilemma. All 21 linear layers of a Safhire-style ResNet-20 are recovered with zero error from real TFHE transcripts using 5,712 queries; the same zero-error behavior holds on eight ImageNet-scale CNNs and on ViT-B/16. The leakage supports fingerprinting, lineage attribution, and faster logit-based extraction, and any noise level large enough to suppress it destroys inference accuracy.

Background: the Safhire setting

Plaintext lattice and correctness. Safhire follows the TFHE torus convention: plaintexts lie on $\mathbb{T}_p := \tfrac{1}{p}\mathbb{Z}/\mathbb{Z}$ with $p = 2^b$, typically $b \in \{8, 12, 16\}$. An RLWE ciphertext with additive noise $e$ decrypts correctly when

$$|e| < \frac{1}{2p}, \qquad \gamma := \frac{1}{p}, \qquad \Delta < \frac{\gamma}{2}. \tag{1}$$

Here $\gamma$ is the quantization step and $\Delta$ the correctness-bounded noise magnitude. Equation 1 is the single operational fact the whole attack rests on: decoded layer outputs are observed on a known lattice and perturbed by less than half a lattice step.

Batched protocol. Inference runs in $L$ rounds, one per linear layer. In round $r$ the server undoes the previous permutation with $\sigma_{r-1}^{-1}$, homomorphically evaluates $y = W_r x + b_r$, applies the round-$r$ output permutation $\sigma_r$, and returns the ciphertext. The client decrypts, applies coordinate-wise ReLU, and re-encrypts. Permutations are derived from a secret session seed, fixed within a session and re-randomized across sessions. The final layer is left unshuffled so the client can read the $\arg\max$ directly.

Threat model (adopted verbatim from Safhire). The server is honest-but-curious; the client may send arbitrary inputs and may try to reverse-engineer the model. There is no distributional restriction, no plaintext validation, and no zero-knowledge proof of well-formedness. Since the input encoding packs a flattened feature chunk into RLWE plaintext coefficients, the basis inputs $\{0, e_1, \dots, e_d\}$ used by the attack are admissible plaintext polynomials.

The shuffle-DP template. A mechanism $\mathcal{M}$ is $(\varepsilon, \delta)$-DP if $\Pr[\mathcal{M}(D) \in S] \le e^{\varepsilon}\Pr[\mathcal{M}(D') \in S] + \delta$ for all neighboring $D, D'$ and measurable $S$. In the shuffle model, $n$ local randomizers privatize their inputs and a trusted shuffler applies a uniform permutation; if each randomizer is $(\varepsilon_0, \delta_0)$-local DP and the parameters lie in the right regime, the shuffled mechanism enjoys amplified central DP improving roughly as $O(\varepsilon_0/\sqrt{n})$. Permutation-based defenses instantiate this by casting FHE decryption noise as the local randomizer and the secret output permutation as the shuffler.

The scheme class: permutation-based protection

Notation. For $v \in \mathbb{R}^m$, $\mathrm{sort}(v)$ arranges entries in non-decreasing order. For a linear layer $W \in \mathbb{R}^{m \times d}$, $b \in \mathbb{R}^m$, the sorted column spectrum and the ordered family are

$$s_i(W, b) := \mathrm{sort}(W_{:,i} + b), \qquad \mathcal{L}(W, b) := \bigl(s_1(W,b), \dots, s_d(W,b)\bigr). \tag{2}$$

$\mathcal{L}(W,b)$ is precisely the information preserved under an output-channel permutation.

Definition 1 (Permutation-Based Protection). Let $\mathcal{X} \subseteq \mathbb{R}^d$ be a query space containing $\{0, e_1, \dots, e_d\}$. A scheme is a pair $\Pi = (\mathsf{Query}, \mathsf{Respond})$ where $\mathsf{Query}(x)$ produces a well-formed query object $q$, and $\mathsf{Respond}(W, b, q)$ determines an effective input $x^\star \in \mathbb{R}^d$ and returns a response from which the client obtains

$$\tilde{y} = \pi\bigl(W x^\star + b\bigr) + \eta, \qquad \pi \in S_m \ \text{secret}, \qquad \lVert \eta \rVert_\infty < \Delta. \tag{3}$$

If the scheme uses a hidden input permutation then $x^\star = \rho(x)$ for a secret $\rho \in S_d$; otherwise $x^\star = x$. The scheme has quantization step $\gamma$ if for every $x \in \{0, e_1, \dots, e_d\}$ the vector $W x^\star + b$ lies on a lattice of minimum spacing $\gamma$.

Remark 1 (how the definition binds).

  • Definition 1 subsumes the Safhire round-$r$ interface via $x^\star = \sigma_{r-1}^{-1}(x)$ and $\pi = \sigma_r$, with $\sigma_0 = \mathrm{id}$ in the first round; $x^\star = x$ recovers the output-shuffling-only interface.
  • The client issues adaptive chosen queries $x^{(1)}, x^{(2)}, \dots \in \mathcal{X}$ and observes the decoded responses $\tilde{y}^{(t)}$.
  • The zero query guarantees $b$ lies on the same lattice as the basis responses; if the relevant values lie in $\tfrac{1}{p}\mathbb{Z}$ one may take $\gamma = 1/p$.
  • In FHE instantiations $\mathsf{Query}$ is client-side encryption and $\mathsf{Respond}$ returns a ciphertext whose decryption yields $\tilde{y}$.

Three hypotheses are isolated for later reuse: (P) the client observes shuffled, noisy outputs of $Wx + b$; (N) the noise satisfies the correctness bound on a known quantization lattice; (C) the client may issue chosen-input queries. A scheme that augments queries with zero-knowledge well-formedness proofs would violate (C) and fall outside the definition; none of the schemes studied does so.

Main result: exact sorted-spectrum recovery

Theorem 1 (Exact Sorted-Spectrum Recovery). Let $\Pi$ satisfy Definition 1 with noise bound $\Delta$ and quantization step $\gamma \ge 2\Delta$. Conditioned on $\lVert \eta \rVert_\infty < \Delta$, there is an efficient adversary $\mathcal{A}$ that, using $d+1$ adaptive queries, recovers $\mathrm{sort}(b)$ from the zero query and the sorted-spectrum multiset $\{\!\{\mathrm{sort}(W_{:,j} + b)\}\!\}_{j=1}^{d}$ from the $d$ basis queries $e_1, \dots, e_d$. Recovery is exact on every noise realization satisfying the bound.

Proof mechanism. Let $Q_\gamma$ denote rounding to the nearest $\gamma$-lattice point and define the round-then-sort operator

$$\mathrm{RTS}(\tilde{y}) := \mathrm{sort}\bigl(Q_\gamma(\tilde{y})\bigr). \tag{4}$$

Bias recovery: for $x = 0$ the response is $\tilde{y} = \pi(b) + \eta$; since $b$ lies on the $\gamma$-lattice and $|\eta_j| < \Delta \le \gamma/2$, rounding recovers $\pi(b)$ exactly and sorting yields $\mathrm{sort}(b)$. Spectrum recovery: for $x = e_i$ the effective input is $x^\star = \rho(e_i) = e_{\rho(i)}$, so the server computes $W_{:,\rho(i)} + b$ and the same round-then-sort argument recovers $\mathrm{sort}(W_{:,\rho(i)} + b)$ exactly. As $i$ ranges over $[d]$ and $\rho$ is a bijection, the adversary obtains the full multiset.

Why this is distribution-agnostic. All response-side randomness is eliminated by rounding, so the recovered output is a deterministic function of $W$ and $b$. The guarantee depends only on $\lVert \eta \rVert_\infty < \Delta$ and is therefore independent of the output-permutation strategy, the noise law, and any DP parameter attached to the scheme. A DP parameter $\varepsilon$ constrains the ratio of output distributions across neighboring inputs for a fixed model, and thus touches no quantity the attack uses.

When $\rho = \mathrm{id}$ the leak is stronger. In Safhire's first round no hidden input permutation is applied, so the recovered spectra are labeled by the queried column indices: the adversary obtains the full ordered family $\mathcal{L}(W, b)$, not merely its underlying multiset.

Proposition 1 (Query Complexity Tightness). With $b = 0$, any adaptive adversary that recovers $\{\!\{\mathrm{sort}(W_{:,j})\}\!\}_{j=1}^{d}$ on every instance needs at least $d$ queries. Proof: with $k \le d-1$ queries the span $V = \mathrm{span}\{x^{(1)}, \dots, x^{(k)}\}$ has dimension $< d$, so there is a unit $v \perp x^{(t)}$ for all $t$. Setting $W' := W + u v^{\mathsf{T}}$ for nonzero $u$ gives $W' x^{(t)} = W x^{(t)} + u\,(v^{\mathsf{T}} x^{(t)}) = W x^{(t)}$, so the two models are view-identical under any permutation strategy and noise realization, yet for generic $W, u$ their sorted-spectrum multisets differ. Combined with Theorem 1 this pins the exact minimax query complexity: $d$ for bias-free layers, $d+1$ when $\mathrm{sort}(b)$ must also be recovered.

Corollary 1 (Safhire's first round). At precision $p$, $\gamma = 1/p$ and $\Delta = 1/(2p)$, so $\gamma = 2\Delta$ and the condition $\lVert \eta \rVert_\infty < \gamma/2$ is exactly the FHE correctness condition. Under standard lattice-based parameters it fails only with negligible probability, typically below $2^{-128}$. Hence over at most $\mathrm{poly}(\lambda)$ queries exact recovery holds with probability $1 - \mathrm{negl}(\lambda)$.

Tightness of the noise bound (Proposition 6, Appendix B). If $\Delta > \gamma/2$, no deterministic lattice-valued algorithm can guarantee exact recovery. Fix $\eta^\star \in (\gamma/2, \min(\gamma, \Delta))$; instance A with true value $k\gamma$ and noise $\eta^\star$ and instance B with true value $(k{+}1)\gamma$ and noise $\eta^\star - \gamma$ (where $|\eta^\star - \gamma| = \gamma - \eta^\star < \gamma/2 < \Delta$) produce the identical observation $o = k\gamma + \eta^\star$, forcing any deterministic algorithm to err on one of them. So $\gamma \ge 2\Delta$ is exactly the right hypothesis.

Why the differential-privacy justification collapses

The paper attacks the DP argument on two independent fronts: it is aimed at the wrong object, and its premise cannot be met.

Front 1: input DP is orthogonal to model confidentiality

For a fixed model $W$, input DP bounds the ratio of output distributions induced by two neighboring inputs $x, x'$. Model confidentiality concerns the distinguishability of two different models under a fixed input. The two quantifications are logically independent.

Definition 2 (Model confidentiality game). $\mathcal{A}$ selects challenge models $(W_0, b_0), (W_1, b_1)$ whose sorted-spectrum multisets differ, $\{\!\{s_i(W_0, b_0)\}\!\} \neq \{\!\{s_i(W_1, b_1)\}\!\}$, the challenger samples $\beta \xleftarrow{\$} \{0,1\}$ and grants oracle access to $\Pi.\mathsf{Respond}(W_\beta, b_\beta, \cdot)$; $\mathcal{A}$ issues adaptive queries and outputs $\hat{\beta}$. The advantage is

$$\mathrm{Adv}^{\mathrm{mc}}_{\Pi, \mathcal{A}} := \bigl|\,2\Pr[\hat{\beta} = \beta] - 1\,\bigr|. \tag{5}$$

Proposition 2. For $\gamma \ge 2\Delta$ there is an adversary issuing $d$ chosen queries with $\mathrm{Adv}^{\mathrm{mc}}_{\Pi, \mathcal{A}} = 1$, regardless of any input DP guarantee satisfied by $\Pi.\mathsf{Respond}$. The $d$ basis queries reveal $M_\beta := \{\!\{\mathrm{sort}(W_{\beta,:,j} + b_\beta)\}\!\}_{j=1}^d$ by Theorem 1 (independently of the hidden $\rho$, since $\rho$ is a bijection on $[d]$), and $M_0 \neq M_1$ by construction, so the adversary outputs the unique matching bit.

Front 2: the local-DP premise is unattainable

Proposition 3. Let $\mathcal{M}_k(x) = (Wx + b)_k + \eta_k$ be the per-coordinate output, with each noise coefficient almost surely in $(-B, B)$ where $B < \gamma/2$ (the correctness-conditioned bounded-noise regime). Suppose for some coordinate $k$ the DP sensitivity satisfies

$$\Delta f := \bigl|(Wx + b)_k - (Wx' + b)_k\bigr| \ \ge\ \gamma. \tag{6}$$

Then any $(\varepsilon_0, \delta_0)$-DP guarantee for $\mathcal{M}_k$ on the pair $(x, x')$ with finite $\varepsilon_0$ necessarily satisfies $\delta_0 \ge 1$; equivalently, $\mathcal{M}_k$ cannot be $(\varepsilon_0, \delta_0)$-DP for any $\delta_0 < 1$. (Note $\Delta f$ is DP sensitivity, unrelated to the noise bound $\Delta$.)

Proof sketch. With $c_x := (Wx+b)_k$, supports satisfy $I_x \subseteq [c_x - B, c_x + B]$ and $I_{x'} \subseteq [c_{x'} - B, c_{x'} + B]$. Take $S := I_x \setminus I_{x'}$. The DP condition on $S$ gives $\Pr[\mathcal{M}_k(x) \in S] \le e^{\varepsilon_0}\Pr[\mathcal{M}_k(x') \in S] + \delta_0$, and $S \cap I_{x'} = \emptyset$ makes the middle term zero, so $\Pr[\mathcal{M}_k(x) \in S] \le \delta_0$. Since $B < \gamma/2$, a gap $\Delta f \ge \gamma$ implies $\Delta f > 2B$, so the two intervals are disjoint, $S = I_x$, and $\Pr[\mathcal{M}_k(x) \in S] = 1$. Hence $\delta_0 \ge 1$.

The proof uses only the almost-sure support bound, needing no density or absolute continuity, so it applies equally to discretely supported RLWE noise and to almost-surely bounded continuous surrogates.

Remark 2 (beyond $(\varepsilon_0, \delta_0)$-DP). An unbounded Gaussian falls outside the hypothesis since then $I_x = \mathbb{R}$ and the disjoint-support argument fails; but any Gaussian wide enough to overlap adjacent lattice points already violates $|\eta| < \gamma/2$ with non-negligible probability. Within the bounded-noise regime, disjoint supports give total variation $\mathrm{TV}(\mathcal{M}_k(x), \mathcal{M}_k(x')) = 1$, so any divergence-based privacy notion that upper-bounds total variation becomes infinite or vacuous on such neighbors. The obstruction extends to group privacy, since a single lattice-step gap already gives $\Delta f > 2B$.

The gap is unavoidable in Safhire. For the basis queries of Theorem 1, moving from $x = 0$ to $x = e_i$ changes the $k$-th output coordinate by an entry of $W_{:,i}$, which lies on the lattice of spacing $\gamma$. So any scheme with at least one nonzero weight entry admits neighbors to which Proposition 3 applies, and $\delta_0 \ge 1$ means no choice of shuffle size $n$, target $\delta$, or Gaussian-surrogate noise restores the guarantee. Restricting the amplification analysis to neighbors with $\Delta f < \gamma$ is unavailable: Safhire's threat model places no bound on $\lVert x \rVert$. Even an artificially sensitivity-restricted variant would recover only an input-privacy guarantee, which Proposition 2 shows is orthogonal to model confidentiality.

Noise/utility tradeoff: a distribution-free lower bound

The natural remedy is to relax the correctness bound and inject larger noise, trading decryption accuracy for defense. The paper establishes a distribution-free lower bound on how much noise that would take.

Proposition 4 (Rounding error under relaxed noise). With relaxed bound $B > 0$ (not necessarily $B \le \gamma/2$) and $\tilde{s}_i := \mathrm{sort}(Q_\gamma(\pi(W_{:,i} + b) + \eta))$, for every column $i$ and every realization with $\lVert \eta \rVert_\infty < B$,

$$\lVert \tilde{s}_i - s_i(W, b) \rVert_\infty \ \le\ \tilde{B} := \gamma \left\lfloor \frac{B}{\gamma} + \frac{1}{2} \right\rfloor \ \le\ B + \frac{\gamma}{2}. \tag{7}$$

The proof writes $v := \pi(W_{:,i} + b) \in \gamma\mathbb{Z}^m$, bounds $|Q_\gamma(v_j + \eta_j) - v_j| \le \tilde{B}$ coordinatewise, and uses the facts that $\mathrm{sort}$ is invariant under $\pi$ and that order statistics are non-expansive in $\ell_\infty$.

Theorem 2 (Noise/Utility Tradeoff). Let $\mathcal{F}$ be a finite model family and $\phi: \mathcal{L} \mapsto \phi(\mathcal{L}) \in (\mathbb{R}^k, \lVert \cdot \rVert_q)$ a fingerprint map satisfying the Lipschitz condition

$$\lVert \phi(\mathcal{L}) - \phi(\mathcal{L}') \rVert_q \ \le\ L_\phi \cdot \max_i \lVert s_i - s_i' \rVert_\infty \quad \text{for some } L_\phi > 0. \tag{8}$$

Define the intrinsic separation $\Delta^{\phi}_{\mathcal{F}} := \min_{M \neq M' \in \mathcal{F}} \lVert \phi(\mathcal{L}(M)) - \phi(\mathcal{L}(M')) \rVert_q$, and let $\mathcal{A}_\phi$ be the round-then-sort nearest-neighbor classifier under $\phi$ given the $d+1$ queries $x = 0, e_1, \dots, e_d$. Then, independently of the noise distribution:

$$\text{(i)}\quad L_\phi \tilde{B} < \frac{\Delta^{\phi}_{\mathcal{F}}}{2} \ \Longrightarrow\ \mathcal{A}_\phi \text{ identifies every } M \in \mathcal{F} \text{ on every realization}; \qquad \text{(ii)}\quad \text{defeating } \mathcal{A}_\phi \text{ requires } B \ \ge\ \max\left\{0,\ \frac{\Delta^{\phi}_{\mathcal{F}}}{2 L_\phi} - \frac{\gamma}{2}\right\}. \tag{9}$$

Part (i) follows from the reverse triangle inequality: $\lVert \phi(\tilde{\mathcal{L}}) - \phi(\mathcal{L}(M')) \rVert_q \ge \Delta^{\phi}_{\mathcal{F}} - L_\phi \tilde{B} > L_\phi \tilde{B} \ge \lVert \phi(\tilde{\mathcal{L}}) - \phi(\mathcal{L}) \rVert_q$. Part (ii) is the contrapositive combined with Equation 7.

Remark 3 (the concrete fingerprint). Section 5 uses the column-norm fingerprint

$$\phi(\mathcal{L}) := \mathrm{sort}\bigl(\lVert s_1 \rVert_2, \dots, \lVert s_d \rVert_2\bigr) \qquad \text{with } \ell_2 \text{ nearest neighbor}, \tag{10}$$

which satisfies Equation 8 with $L_\phi = \sqrt{md}$: if $\max_i \lVert \tilde{s}_i - s_i \rVert_\infty \le e$ then $|\lVert \tilde{s}_i \rVert_2 - \lVert s_i \rVert_2| \le \sqrt{m}\,e$ per column (via $\lVert \cdot \rVert_2 \le \sqrt{m} \lVert \cdot \rVert_\infty$), and non-expansiveness of $\mathrm{sort}$ together with $\lVert \cdot \rVert_2 \le \sqrt{d} \lVert \cdot \rVert_\infty$ on $\mathbb{R}^d$ gives $\lVert \phi(\tilde{\mathcal{L}}) - \phi(\mathcal{L}) \rVert_2 \le \sqrt{md}\,e$. For ResNet-20 conv1 with $m = 16$, $d = 27$ at 8-bit precision and $\Delta^{\phi}_{\mathcal{F}} \approx 0.298$, Theorem 2 yields $B \ge 2.7\,(\gamma/2)$.

The authors are explicit that this bound certifies attack success below the threshold, not defender safety above it. The certified $2.7\,(\gamma/2)$ sits two to three orders of magnitude below the empirical transition at $10^2$–$10^3\,(\gamma/2)$, because the worst-case $L_\phi = \sqrt{md}$ assumes adversarial alignment across all $m$ coordinates whereas symmetric noise gives a tighter $\sqrt{m}$ scaling. Taken together: Theorem 1 covers $B < \gamma/2$, $\delta_0 \ge 1$ rules out the shuffle route, and Theorem 2 ties brute-force noise to intrinsic fingerprint separation.

The chosen-input attack on multi-round Safhire

Multi-round layers. In round $r$ the server applies $\sigma_{r-1}^{-1}$ before evaluating layer $r$ and $\sigma_r$ afterward, so a basis query $e_i$ in round $r$ probes column $\sigma_{r-1}^{-1}(i)$ of $W_r$. Because $\sigma_{r-1}$ is fixed within a session, the $d$ basis queries in round $r$ collectively probe every column of $W_r$ exactly once, keeping the budget at $d+1$ per layer.

Proposition 5 (fresh permutation per request). If $\sigma_{r-1}$ is resampled independently for each inference request, all distinct sorted spectra of $W_r$ can still be recovered with $O(d \log d)$ queries. Precisely, recovery succeeds with probability at least $1 - e^{-c}$ whenever the query count $T$ satisfies

$$T \ \ge\ d\,(\ln d^{*} + c), \qquad d^{*} \le d \ \text{the number of distinct spectra}. \tag{11}$$

This is a coupon-collector argument: each query probes a uniformly random column, a distinct spectrum $s$ of multiplicity $m_s$ is hit with probability $m_s/d \ge 1/d$, so $T$ independent queries all miss $s$ with probability at most $(1 - 1/d)^T \le e^{-T/d}$; a union bound over $d^{*}$ spectra gives $d^{*} e^{-T/d} \le e^{-c}$. Duplicate recoveries are removed by equality testing on the sorted vectors.

On trained ResNet-20 the authors observe $d^{*} = d$ in every layer (no duplicate spectra), so Equation 11 gives roughly 5,400 queries for the widest layer ($d = 576$, $c = 3$). In simulation the independently-resampled-permutation attack converges with $T_{\mathrm{emp}}/T_{\mathrm{theory}} \in [0.58, 0.87]$ over 5 trials per layer.

What exactly is recovered. Per layer the adversary obtains $\mathcal{L}(W, b)$ and hence every permutation-invariant statistic derived from it: the affine column norms $\lVert W_{:,i} + b \rVert_2$ and the empirical value distribution of each column. For bias-free layers, where $b = 0$ as is standard under batch normalization, this reduces to the exact weight multisets $\mathrm{sort}(W_{:,i})$, their column norms, and the Frobenius norm $\lVert W \rVert_F$. Because $\mathrm{sort}$ does not commute with subtraction, the bias cannot be disentangled from the weights in general, but this residual ambiguity affects none of the downstream applications.

Safhire treats leakage of only the weight histogram as benign residual leakage bounded by a shuffle-model DP guarantee. Proposition 2 shows that guarantee is formulated in the wrong direction and Proposition 3 shows its local-DP premise fails under the correctness bound, so the residual-leakage defense has no formal backing.

Comparison with prior extraction. Classical extraction attacks need many queries because nonlinearities such as softmax obscure the linear layers: the cryptanalytic attack of Carlini et al. uses $2^{18.5}$–$2^{21.5}$ queries on 4K–100K-parameter MLPs. SEEK extracts approximate weights from an 11.7M-parameter ResNet-18 over HE/MPC using fewer than 50 queries per parameter (about $5 \times 10^{8}$ total) with relative error about $3 \times 10^{-4}$; its leverage is arbitrary intermediate-feature shifts, not a permuted linear snapshot, so it does not target Definition 1. This attack needs only $d+1$ queries per layer, totaling 5,712 on a 0.27M-parameter ResNet-20, because permutation-based protection directly exposes a sorted linear-layer snapshot.

Training setup (Appendix A). The 20 ResNet-20 checkpoints use SGD with learning rate 0.1, momentum 0.9, weight decay $10^{-4}$, MultiStepLR milestones at epochs 5 and 8, batch size 128, 10 epochs, seeds $0, \dots, 19$, giving mean test accuracy 82.8%. Theorem 1 is deterministic under the correctness bound, so zero-error recovery does not depend on teacher accuracy; longer training affects only the fingerprint-separation constant $\Delta^{\phi}_{\mathcal{F}}$. All 21 convolution modules use bias=False, so before BN folding $b = 0$ and the raw convolution reduces to the exact weight multiset. BN layers are folded into the preceding convolution by the standard deployment transform

W  ->  gamma_BN * W / sigma_BN
b  ->  gamma_BN * (mu_conv - mu_BN) / sigma_BN + beta_BN

(the paper reuses the symbol $\gamma$ for the BN scale here; it is distinct from the quantization step $\gamma = 1/p$). The recovered object is therefore the folded affine pair $(W', b')$ that the client actually sees as the layer output. Residual branches $y = F(x) + x$ are probed branchwise, consistent with Safhire's per-layer ciphertext reply pattern. Per-layer input dimensions $d_l$ range from 16 (layer2.0.shortcut) to 576 (layer3.2.conv2).

Practical impact of sorted-spectrum leakage

The defender's residual claim is that losing column labels renders the recovered multisets benign, since the weight matrix cannot be reconstructed even up to row and column permutations. The paper argues this substantially understates the leakage: many security-relevant quantities are permutation-invariant and hence fully determined by $\mathcal{L}(W, b)$ - column norms, the per-column empirical distributions $s_i(W, b)$, and the weight-value histogram. Three concrete consequences follow.

Fingerprinting

Independently trained models with the same architecture converge to different local minima under different seeds, so their sorted column spectra are deterministically distinct. Using the 20 ResNet-20 checkpoints and the conv1 column-norm fingerprint of Equation 10, the within-model distance is zero across all noise realizations (recovery is exact), while the minimum between-model distance is $\Delta^{\phi}_{\mathcal{F}} = 0.298$. All $\binom{20}{2} = 190$ pairs are perfectly separable. On CIFAR-100 the same fingerprint gives $\Delta^{\phi}_{\mathcal{F}} = 0.565$ after 200 epochs, again separating all 190 pairs. Each pair instantiates Definition 2 empirically: the round-then-sort adversary of Proposition 2 achieves $\mathrm{Adv}^{\mathrm{mc}} = 1$ on all 190 challenge pairs using $d$ basis queries, or a single query in the first-round setting where $\rho = \mathrm{id}$. Because $\phi$ is column-permutation invariant, the multiset-level recovery of Theorem 1 suffices; the stronger labeled recovery is unnecessary.

Lineage detection

Fine-tuning perturbs weights incrementally, so a child's sorted column spectrum stays closer to its parent's than to an independently trained checkpoint's. Taking 5 of the 20 checkpoints as bases, fine-tuning three children per base (mild, moderate, aggressive regimes), and classifying each child against all 20 bases by $\ell_2$ nearest-neighbor search on sorted column norms concatenated across three convolutional layers gives separation ratios (minimum between-base distance over maximum within-base distance) of 26.7, 6.0, and 1.59. All exceed 1, yielding 15/15 correct attributions and zero false positives over 285 non-lineage pairs.

At ImageNet scale, the same fingerprint on torchvision ResNet-50 V1 and V2 plus a lineage variant $V_1^{\mathrm{ft}}$ (V1 fine-tuned for two epochs on Imagenette) gives $\lVert \phi(V_1) - \phi(V_2) \rVert_2 = 1106.43$ versus $\lVert \phi(V_1) - \phi(V_1^{\mathrm{ft}}) \rVert_2 = 1.38$, an approximate 800:1 lineage-to-non-lineage distance ratio on a 25.5M-parameter backbone. Since $V_1^{\mathrm{ft}}$ stays in $V_1$'s fine-tuning neighborhood, $\lVert \phi(V_2) - \phi(V_1^{\mathrm{ft}}) \rVert_2$ agrees with $\lVert \phi(V_1) - \phi(V_2) \rVert_2$ to four significant digits.

The privacy/utility dilemma

Safhire suggests increasing the output noise level as a possible countermeasure. Since its shuffle-DP argument treats each round's convolution output as a local randomizer, the natural reading is to increase noise at every layer. Reading the sweep. Fingerprinting remains fully effective up to a $100\times$ multiplier with essentially no utility loss: all 20 ResNet-20 models are still identified and per-layer agreement is 98.3%. It breaks down only at $\ge 1{,}000\times$, where accuracy has already fallen to 59.0% (ResNet-20) and 48.9% (ResNet-56). For ImageNet-scale ResNet-50 on Imagenette ($N = 20$), utility collapses between $30\times$ and $70\times$, about an order of magnitude earlier than on CIFAR because noise compounds across 53 layers.

Figure 1 plots the phase transition directly: the ResNet-56 CIFAR-10 curve uses $N = 100$ over nine noise levels and the ResNet-50 Imagenette curve $N = 20$, both clipped-Gaussian at $p = 256$, with attack error on the right axis and $\gamma/2 = 1/512$ marked for reference. The shaded band is the region where the attack would be broken while utility stays intact - neither curve ever enters it.

The ImageNet-scale protocol behind that curve uses a fixed 500-image Imagenette-val subset (50 per class, random.seed(0)) scored top-1 against real ImageNet-1K labels via the WNID-to-index map; the lineage variant $V_1^{\mathrm{ft}}$ is $V_1$ after two epochs of SGD on the same subset at learning rate $10^{-3}$, batch 32.

No distribution rescues the defender. Across all six bounded noise distributions tested (zero, Gaussian, triangular, Laplace, uniform, and the worst-case deterministic envelope $\eta_k \in \{+B, -B\}$) no distribution reverses the ordering; a smoother noise law can at best delay the collapse by a constant factor. Appendix C figures at multiplier $m = 1{,}000$ (ResNet-20 / ResNet-56): Gaussian 59.0% / 48.9%, triangular 41.3% / 29.8%, Laplace 21.6% / 13.6%, uniform 18.7% / 12.5%; the worst-case envelope is the most damaging, at 76.8% / 75.6% for $m = 100$ and 10.0% for both at $m = 1{,}000$. Under zero noise the two models retain 82.3% and 82.2% at both $m = 100$ and $m = 1{,}000$.

Repetition beats noise. Repeating each column query $k$ times and averaging reduces recovery error by a factor $1/\sqrt{k}$: at $1{,}000\times$ noise, $k = 5$ lowers the mean error from 0.92 to 0.38. So increasing noise raises the adversary's query cost quadratically rather than preventing recovery.

Discussion: coverage across the scheme class and what a real defense needs

Which schemes are actually broken. Theorem 1 rests on hypotheses (P) shuffled noisy outputs of $Wx + b$ are observed, (N) noise satisfies the correctness bound on a known quantization lattice, and (C) the client may issue chosen inputs. Related schemes satisfy different subsets:

Scheme(P)(N)(C)Status
SafhireyesyesyesPrimary target; all three hold at every layer under its stated threat model
STIP-nonoExact floating-point computation, activations stay encrypted/secret-shared, only final output revealed
Centaur-nonoSame reason as STIP; Theorem 1 yields no meaningful client-side attack
Fissionno--MPC protocol; never reveals a permuted layer output to the client (included only for hypothesis-level comparison)
PermLLM---Outside Definition 1: its permutation acts on the sequence axis, not the output-channel axis $\pi \in S_m$

Compound leakage. The attack recovers $s_i(W, b)$ rather than the full weight matrix, but in Safhire the final layer is left unshuffled to enable client-side $\arg\max$. The recovered spectra therefore combine with exact logit access into a compound channel exposing both the model's functionality and its identity.

Necessary conditions for a defense. Any viable defense must invalidate at least one hypothesis of Theorem 1. Three broad escape routes exist:

  • Secret linear transforms that mask $Wx + b$ so it is computationally indistinguishable from random without the key - violates (P).
  • Function secret sharing across non-colluding servers, so no single party observes the permuted output - violates both (P) and (C). GAZELLE, DELPHI, and CrypTFlow2 instantiate variants of this route, at the bandwidth cost that permutation-based schemes were meant to avoid.
  • Fully server-side FHE, withholding intermediate decryptions from the client - violates (C).

Per-query permutations do not help. Because the recovered quantity is a permutation-invariant summary, Theorem 1 holds for any permutation strategy, including drawing a fresh permutation for every query. Table 1 confirms this empirically: the fresh-per-query regime leaves maximum recovery error at zero across all 21 layers.

The source states only that STIP and Centaur violate (N) and (C); the table leaves (P) unmarked for them accordingly.

Relation to prior work. Conditional impossibility results are known for black-box observational defenses of polynomial-size decision trees under subexponential LPN, and for learnability-preserving data encoding. This result is incomparable: it gives an unconditional guarantee of exact sorted-spectrum recovery on the narrower channel of Definition 1. ArrowMatch empirically shows that TEE-shielded weight obfuscation alone fails against adaptive clients. The sorted-leakage channel exploited here is a known-severe one: inference attacks on property-preserving encrypted databases established the same pattern. The link between extraction and fingerprinting, together with membership inference, supports treating identification-level leakage as a model-confidentiality threat in the first place. On the input side, prior work uses sequential-token markers to recover client input tokens in PermLLM, STIP, and Centaur, which is disjoint from this chosen-input attack on model parameters; other work attacks pure-FHE and split-model FHE LLM inference outside the permutation class. Finally, the authors note that the closest prior noise-based defense study injects Gaussian noise into input embeddings against input-privacy attacks on transformers, differing in both attack target and injection point, and that to their knowledge no prior work quantifies per-layer noise as a defense against model-confidentiality attacks in this scheme class.

Algorithms

Complete at-a-glance pseudocode for every procedure the paper defines or references.

Algorithm 1: Safhire round-$r$ interface (the target protocol)

Input:  client activation x_{r-1} (encrypted), server layer (W_r, b_r),
        secret session permutations sigma_0 = id, sigma_1, ..., sigma_L,
        precision p, quantization step gamma = 1/p
Output: client-side plaintext activation x_r

Server:
  1. receive ciphertext Enc(x_{r-1})            # x_{r-1} is sigma_{r-1}-shuffled
  2. z  <- sigma_{r-1}^{-1}(x_{r-1})            # undo previous round permutation
  3. y  <- W_r * z + b_r                        # homomorphic linear evaluation
  4. y' <- sigma_r(y)                           # apply round-r output permutation
  5. send Enc(y')                               # decryption noise eta, |eta|_inf < gamma/2

Client:
  6. y~ <- Dec(Enc(y')) = sigma_r(W_r z + b_r) + eta
  7. x_r <- ReLU(y~)                            # ReLU commutes with coordinate permutation
  8. re-encrypt x_r for round r+1
Note: the final layer L is left unshuffled so the client can read argmax directly.

Algorithm 2: Round-then-sort recovery (Theorem 1) - the main attack

Input:  oracle access to Pi.Respond(W, b, .) for a d-input, m-output linear layer;
        quantization step gamma; noise bound Delta with gamma >= 2*Delta
Output: sort(b) and the multiset {{ sort(W[:,j] + b) : j in [d] }}
Queries: d + 1

  define Q_gamma(v)   := coordinatewise rounding of v to the nearest gamma-lattice point
  define RTS(y~)      := sort(Q_gamma(y~))

  1. y~_0 <- Respond(Query(0))                  # zero query;  y~_0 = pi(b) + eta
  2. s_b  <- RTS(y~_0)                          # = sort(b), exact since |eta| < gamma/2
  3. M    <- empty multiset
  4. for i = 1 to d:
  5.     y~_i <- Respond(Query(e_i))            # = pi(W[:,rho(i)] + b) + eta
  6.     s_i  <- RTS(y~_i)                      # = sort(W[:,rho(i)] + b), exact
  7.     insert s_i into M
  8. return (s_b, M)

Guarantees:
  - exact on EVERY noise realization with |eta|_inf < Delta (no distributional assumption)
  - independent of the permutation strategy pi, of the noise law, and of any DP parameter
  - if rho = id (Safhire round 1), the s_i are labeled by column index, so the
    ORDERED family L(W,b) = (s_1, ..., s_d) is recovered, not merely the multiset
  - d queries are necessary (Proposition 1); d+1 is optimal when sort(b) is also needed
  - if Delta > gamma/2 no deterministic lattice-valued algorithm succeeds (Proposition 6)

Algorithm 3: Model-confidentiality distinguisher (Proposition 2)

Input:  challenge models (W_0, b_0), (W_1, b_1) with distinct sorted-spectrum multisets;
        oracle Pi.Respond(W_beta, b_beta, .) for a hidden bit beta
Output: bit beta_hat  with advantage |2*Pr[beta_hat = beta] - 1| = 1
Queries: d  (or 1 in the first-round setting where rho = id)

  1. for i = 1 to d:  y~_i <- Respond(Query(e_i))
  2. M_obs <- {{ RTS(y~_i) : i in [d] }}         # Algorithm 2, spectrum part only
  3. M_0   <- {{ sort(W_0[:,j] + b_0) : j in [d] }}
  4. M_1   <- {{ sort(W_1[:,j] + b_1) : j in [d] }}
  5. return the unique beta_hat in {0,1} with M_{beta_hat} == M_obs
Correctness: M_0 != M_1 by the game definition; M_obs is recovered exactly by
Algorithm 2 regardless of the hidden input permutation rho, since rho is a bijection.

Algorithm 4: Recovery under fresh-per-request permutations (Proposition 5)

Input:  oracle for layer W_r whose sigma_{r-1} is resampled independently per request;
        confidence parameter c;  d* = number of distinct sorted spectra (d* <= d)
Output: the set of all distinct sorted spectra of W_r
Queries: T >= d * (ln d* + c)     =>  failure probability <= e^{-c}

  1. S <- empty set
  2. T <- ceil( d * (ln d* + c) )                # coupon-collector bound
  3. for t = 1 to T:
  4.     pick any basis vector e_i               # probes a uniformly random column
  5.     y~ <- Respond(Query(e_i))
  6.     s  <- RTS(y~)                            # exact by Theorem 1
  7.     if s not equal to any element of S:      # equality test on sorted vectors
  8.         insert s into S
  9. return S

Empirically: on trained ResNet-20, d* = d in every layer (no duplicate spectra), so the
bound gives about 5,400 queries for the widest layer (d = 576, c = 3), and the observed
ratio T_emp / T_theory lies in [0.58, 0.87] over 5 trials per layer.

Algorithm 5: Fingerprinting and lineage attribution (Section 5.1)

Input:  recovered family L~ = (s~_1, ..., s~_d) for the probed layer(s);
        reference set F of candidate models with known spectra
Output: identity (or parent) of the served model

  1. phi(L) := sort( ||s_1||_2, ||s_2||_2, ..., ||s_d||_2 )     # column-norm fingerprint
       # satisfies the Lipschitz condition of Theorem 2 with L_phi = sqrt(m*d)
  2. f_obs <- phi(L~)                                            # from Algorithm 2 output
  3. for each M in F:  dist[M] <- || f_obs - phi(L(M)) ||_2
  4. return argmin_M dist[M]                                     # nearest neighbour

Fingerprinting: within-model distance = 0 (recovery is exact), min between-model
distance Delta_F^phi = 0.298 on 20 ResNet-20 checkpoints => all 190 pairs separable
(CIFAR-100, 200 epochs: 0.565, again all 190 separable).

Lineage: concatenate sorted column norms across three convolutional layers and run the
same nearest-neighbour search against the base checkpoints. Separation ratio
  (min between-base distance) / (max within-base distance)
was 26.7 / 6.0 / 1.59 for mild / moderate / aggressive fine-tuning; all > 1,
giving 15/15 correct attributions and 0 false positives over 285 non-lineage pairs.

Certified regime (Theorem 2): if L_phi * B~ < Delta_F^phi / 2, where
B~ = gamma * floor(B/gamma + 1/2) <= B + gamma/2, then this classifier is correct on
every noise realization; defeating it requires B >= max{0, Delta_F^phi/(2*L_phi) - gamma/2}.

Algorithm 6: Averaging to defeat relaxed (larger-than-correctness) noise

Input:  oracle with relaxed noise bound B possibly exceeding gamma/2; repetition count k
Output: sorted spectra with recovery error reduced by a factor 1/sqrt(k)

  1. for i = 1 to d:
  2.     for j = 1 to k:  y~_{i,j} <- Respond(Query(e_i))
  3.     ybar_i <- (1/k) * sum_j y~_{i,j}       # noise averages down as 1/sqrt(k)
  4.     s~_i   <- sort(Q_gamma(ybar_i))
  5. return {{ s~_i }}
Measured: at a 1,000x noise multiplier, k = 5 lowers the mean recovery error from
0.92 to 0.38. Raising the noise therefore raises the adversary's query cost
QUADRATICALLY rather than preventing recovery.

Algorithm 7: Per-layer noise-injection defense that is being evaluated

Input:  network layers 1..L, clipped-Gaussian noise scale multiplier mult,
        base scale gamma/2 = 1/(2p)
Output: noised inference output (defender side)

  1. for r = 1 to L:
  2.     y   <- W_r * z_{r-1} + b_r
  3.     eta <- clipped_Gaussian(scale = mult * gamma/2, clip = B)
  4.     y'  <- sigma_r(y) + eta                # noise injected at EVERY layer output
  5.     z_r <- ReLU( Dec(y') )
  6. return z_L
Result (Table 3 / Figure 1): fingerprinting survives to mult = 100x with 98.3%
prediction agreement and unchanged 82.2% accuracy; it breaks only at mult >= 1,000x,
where accuracy has already dropped to 59.0% (ResNet-20) / 48.9% (ResNet-56).
On ImageNet-scale ResNet-50 utility collapses between 30x and 70x. No noise scale,
architecture, or bounded noise distribution defeats the attack while keeping usable
accuracy: the defense family admits no viable operating point.
