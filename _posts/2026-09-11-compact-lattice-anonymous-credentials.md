Anonymous credential systems combine cryptographic authenticity with strong user privacy, and have gained new relevance from the European Digital Identity (EUDI) wallet initiative, which calls for efficient, private solutions with well-understood security foundations amid the post-quantum transition. The authors note that current quantum-safe anonymous credentials based on standard lattice assumptions still lag behind schemes built on more exotic, ad-hoc interactive assumptions in performance. They present techniques to improve the efficiency of anonymous credentials from standard lattice assumptions, with the main improvement coming from tighter approximate range proofs in the zero-knowledge protocol of Lyubashevsky, Nguyen, and Plancon from Crypto 2022, which had been the main efficiency bottleneck for lattice-based privacy constructions. The result narrows the performance gap between standard-assumption lattice credentials and less conservative alternatives.
