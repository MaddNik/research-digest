description: "An experimental study characterizes fading memory in silicon microring resonators under random modulation to assess their usefulness for photonic reservoir computing."
---

Silicon microring resonators are promising building blocks for photonic reservoir computing because their nonlinear optical response, driven by coupled free-carrier and thermal dynamics, can transform input signals and retain information about recent inputs. The authors characterize a single microring resonator and a passive network of microrings under randomly modulated input, rather than the constant excitation typically used to study self-pulsing. They find that the largest fading memory occurs near the self-pulsing boundary, where no clearly resolved oscillation is present, and that reservoir computing metrics such as memory capacity map this accessible memory and its decay timescales, which track free-carrier and thermal relaxation. Using NARMA reconstruction to test nonlinear temporal processing, they show that responses with a resolved self-pulsing-like component actually perform worse on this task because the intrinsic memory profile does not match the required input history. The results indicate that reservoir computing metrics can characterize microring dynamics even in regimes where the physical system is not an effective standalone reservoir for a given task.
