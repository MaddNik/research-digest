Existing private set operation protocols are typically limited to a single function, only semi-honest security, or the two-party setting, leaving the combination of diverse operations, malicious security, and multi-party dishonest-majority settings an open problem. UM-PSO addresses all three at once, presenting what the authors call the first maliciously secure multi-party private set operation framework supporting a broad range of set operations with practical efficiency. The design targets real-world deployments where applications need to run several set operations within the same task rather than building separate protocols for each. The authors, from Nanyang Technological University, Ant Group, Zhongguancun Laboratory, National University of Singapore, and Qingdao University, position it as closing a gap between theoretical multi-party computation generality and the specialized efficiency of prior single-function private set operation protocols.
