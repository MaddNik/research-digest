Realizing universal function approximation in optical hardware requires engineering the computational features encoded in light. The authors show that wavelength diversity enhances the expressivity of optical function approximation through wavelength-scaled Fourier features generated by a shared phase encoder, without increasing the number of input-encoded harmonics, so that multiple wavelengths jointly contribute to representing each output function rather than acting as independent channels. They establish theoretical scaling laws and approximation-error bounds showing that, for nondispersive encoders, the spectral endpoints set the accessible computational bandwidth while intermediate wavelengths enrich the harmonics within that bandwidth. Numerical studies show improved approximation of real- and complex-valued nonlinear functions, with a representative design achieving more than a hundredfold reduction in mean-squared error relative to monochromatic optical processors using the same number of trainable phase features. Experimentally, the authors validate the enhanced approximation accuracy and demonstrate simultaneous approximation of 4,136 distinct nonlinear functions using a compact, single-layer diffractive processor under five-wavelength illumination, establishing wavelength diversity as an additional physical resource for scaling optical computing.
