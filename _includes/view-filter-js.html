{%- comment -%} Site-wide view filter. Loaded once from _layouts/default.html, so it runs on every page. It finds the page's card or tile list, inserts a control bar above it, and offers: Sort: Default order, A to Z, Z to A, Newest first, Oldest first Category: All, plus every distinct category present in the list It reads data-vf-title / data-vf-date / data-vf-cat where the template sets them (papers, resources, deep summaries, conferences, tags). On pages whose markup comes from the theme gem and carries no such attributes (archives, categories, individual tag pages), it falls back to reading the item's heading or link text, its , and its category pill. Controls that would do nothing are not rendered: the sort-by-time options need at least two distinct parseable dates, and the category select needs at least two distinct categories. That is what keeps the category control off a single-topic page. Hiding uses a class with !important rather than inline display, so it composes with the existing per-page .topic-tile filters: an item is visible only when neither control hides it. {%- endcomment -%}
